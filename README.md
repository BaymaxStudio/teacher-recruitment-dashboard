# 广东民办中学 2027 秋招决策台

单页私有网站，用于筛选广州、顺德、深圳及广东湾区民办中学的政治、经济、商科、全球视野和人文岗位。

## 本地运行

```bash
npm ci
npm run dev
```

## 检查与导出

```bash
npm run lint
npm test
npm run check:links   # 批量检测数据文件里的外链状态
npm run export:data
```

- 网站数据：`app/recruitment-data.ts`
- Markdown 清单：`outputs/广东民办中学教师_2027秋招追踪.md`
- JSON 数据：`outputs/广东民办中学教师_2027秋招数据.json`

## 页面功能

- 筛选：城市/区/机构类型/课程/方向/状态/语言/资质/经验/工作安排/跟进状态/风险上限/薪资底线/搜索/排序
- 行动队列：现在可投、先询问、备考参考、等待秋招、低于当前底线
- 收藏（★）、只看收藏、跟进状态、个人备注、最多 4 校比较、复制待办、导出 CSV
- 覆盖检索：深圳 49 所官方民办普高清单、广州民办中学官方名单（按同口径逐校检索）

网站不登录招聘账号、不代投、不联系学校。收藏、跟进状态和个人备注仅写入当前浏览器的 `localStorage`。
